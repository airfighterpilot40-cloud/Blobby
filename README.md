# NEON RIFT // BLOBBY

A deliberately over-the-top browser roguelite built with vanilla HTML, CSS, and JavaScript.

## Features
- Procedural endless waves with scaling difficulty
- Multiple enemy behaviors plus elite variants
- Rift Titan boss every fifth wave
- XP, levels, randomized mutation cards, and local high-score banking
- Dash invulnerability, ultimate Overdrive, crits, piercing shots, and multishot
- Particles, screen shake, neon lighting, responsive HUD
- Zero build step: open `index.html`

## Controls
- **WASD / Arrow Keys** — move
- **Mouse** — aim
- **Left click** — fire
- **Space** — dash
- **Q** — Overdrive ultimate
- **P** — pause

## Run
Open `index.html` in a browser. To publish it, enable GitHub Pages for the repository root.

Go wild. Break the simulation.
